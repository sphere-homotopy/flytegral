# Flytegral

A fruit fly learns to estimate definite integrals from plots.

The demo presents a function graph, lets a visible fly "think", and maps the fly's output to a slider representing

\[
\int_a^b f(x)\,dx.
\]

## MVP

- light, social-friendly browser UI;
- plotted function and highlighted integration interval;
- visible fly between stimulus and answer;
- animated answer slider;
- target, estimate, and absolute error;
- generated benchmark cases with deterministic seeds;
- transparent baseline agent first, connectome-constrained agent second.

The first milestone is intentionally small: validate the interaction, benchmark, and visual language before wiring in the full MaleCNS connectome.
