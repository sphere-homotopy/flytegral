## Limitation

The first eight samples read as coherent, but the grammar is conspicuously repetitive. The semantic cards are finite, and voice variation still only reorders the same material. Success requires learning reusable joke structures from a *reviewed* owner/style corpus, broader conceptual choices, and real human comparisons. Use this preview as a baseline rather than treating it as a deployable product.
